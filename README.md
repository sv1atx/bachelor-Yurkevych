## Опис проєкту

**Minerland** — це 2D гра у жанрі Sandbox / Mining RPG, створена з використанням рушія Unity.

Проєкт орієнтований на дослідження підземного світу, видобуток ресурсів, покращення інструментів та поступовий розвиток персонажа.

Основною метою роботи є створення цілісної візуальної системи гри з використанням Pixel Art графіки, UI/UX-дизайну та інтеграції графічних ресурсів у середовище Unity.

### Основні можливості:

* Pixel Art стиль гри
* UI/UX-дизайн інтерфейсу
* Система інвентарю
* Tilemap-система побудови світу
* Анімації персонажа
* Базова система видобутку ресурсів
* Інтеграція графічних ресурсів у Unity
* Оптимізація графіки та продуктивності



# Інструкція зі встановлення та запуску

## 1. Завантаження проєкту

1. Перейти за посиланням Google Drive
2. Завантажити архів із грою

---

## 2. Розархівування проєкту

1. Відкрити завантажений `.zip` архів
2. Розархівувати папку проєкту у зручне місце, наприклад на Робочий стіл

---

## 3. Запуск гри

1. Відкрити папку `Minerland`
2. Знайти файл:

```plaintext
Minerland.exe
```

3. Запустити файл `Minerland.exe`

Після запуску гра автоматично відкриється та буде готова до використання.


# Примітка

Для коректної роботи гри операційна система Windows може попросити підтвердження запуску файлу. У такому випадку необхідно натиснути:

**"Run anyway" / "Все одно запустити"**
